## Writing style

Applies to everything written for a person to read: code comments, commit messages, pull request descriptions, documents, and prose in replies.

### Punctuation

- PREFER commonly seen punctuation (.,:;?).
- REFRAIN from punctuation that may not read naturally, such as emdash (—). A colon (:) is a potential replacement, or a hyphen (-) where one is needed.

### Line breaks

- Where the text is wrapped at all, ONLY break lines where it makes sense in the context of a sentence: at punctuation, or before a grammatical construct that still flows with a break in front of it. Break also when a line runs TOO LONG (140 characters).
- Pull request descriptions are the exception and are not wrapped at all. See the commit message and pull request rules.
